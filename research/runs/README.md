
# Experiment Runs

Thư mục này dành cho kết quả sinh ra từ các lần chạy thực nghiệm.

Mỗi run nên lưu:
- Metadata.
- Cấu hình.
- Kết quả từng trận hoặc dữ liệu tổng hợp.
- Log lỗi.
- Phiên bản engine và agent.
- Seed.
- Đường dẫn checkpoint nếu có.

Không commit các tệp log lớn theo mặc định.

Kết quả được công bố phải truy xuất được về lần chạy thực tế. Không dùng dữ liệu mẫu như dữ liệu thật.
