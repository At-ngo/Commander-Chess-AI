
# Scripts — Công cụ hỗ trợ

## Mục tiêu

Chứa các script hỗ trợ phát triển và nghiên cứu.

## Các công cụ có thể bổ sung

- Kiểm tra cấu hình thực nghiệm.
- Chạy smoke test.
- Xuất kết quả giải đấu.
- Kiểm tra tính toàn vẹn của replay.
- Tổng hợp số liệu báo cáo.
- Kiểm tra dữ liệu trước khi sử dụng.

## Quy tắc

- Mỗi script phải có mục đích rõ ràng.
- Ghi cách chạy và các tham số.
- Không thực hiện thao tác phá hủy dữ liệu mặc định.
- Kiểm tra đầu vào.
- Trả mã lỗi phù hợp khi thất bại.
- Không tạo hoặc sửa số liệu thực nghiệm để đạt kết quả mong muốn.
