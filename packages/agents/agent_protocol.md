
# Agent Protocol

Status: Draft. Finalize types with the engine implementation.

## Input
An agent receives:
- Current game state.
- Legal actions generated by the authoritative engine.
- Agent configuration.
- Random seed or RNG interface when applicable.
- Optional time or search budget.

## Output
An agent returns:
- One action from the supplied legal-action list.
- Optional diagnostic metadata, such as nodes searched, simulations, or decision time.

## Requirements
- Never mutate authoritative game state.
- Never invent an action outside the legal-action list.
- Handle terminal states and empty action lists explicitly.
- Respect configured resource limits.
- Use reproducible randomness when a seed is provided.
- Fail clearly when no valid action can be returned.
- Let the engine validate and apply the chosen action.

## Example Concept

`select_action(state, legal_actions, config, rng) -> action`

This signature is conceptual, not a finalized implementation contract.

## Metadata
Record agent ID, algorithm, version, configuration, seed, and available search metrics for research games.
